# Environmental Science Club

Website for the Environmental Science Club - Building a sustainable future through innovation, collaboration, and action.

## Overview

This website showcases our club's mission, activities, and provides information for students interested in joining. The site features:

- **About Section**: Our mission, community, and goals
- **Activities Section**: Information about hackathons, website development, and social media initiatives
- **Why Join Section**: Benefits of membership including portfolio building, resume enhancement, and leadership opportunities
- **Join Section**: How to get involved via Remind

## Files

- `index.html` - Main HTML structure of the website
- `styles.css` - CSS styling with custom properties, animations, and responsive design
- `script.js` - JavaScript for page animations, scroll effects, and reveal animations

## Features

- Smooth scrolling navigation
- Sticky header with scroll effect
- Scroll-reveal animations for content sections
- Responsive design
- Clean, modern green theme

## Getting Started

To run locally, simply open `index.html` in a web browser. No build process or dependencies required.

## Hosting

This site can be hosted on:
- **GitHub Pages**: Push to a GitHub repository and enable Pages in settings
- **Netlify**: Connect your GitHub repository for automatic deployments
